## 1. Introduction & Getting Started

### 1.1 What is Google Docs?

Google Docs is a web-based word processing application developed by Google. It allows users to create, edit, format, and share documents online.

Documents are automatically saved to Google Drive, making them accessible across supported devices.

### 1.2 Key Features

- **Cloud-Based Storage:** Documents are saved in Google Drive.
- **Real-Time Collaboration:** Multiple users can work on the same document.
- **Automatic Saving:** Changes are saved automatically.
- **Formatting Tools:** Supports text styling, tables, images, and page layouts.
- **Version History:** Allows users to view and restore earlier versions.
- **Accessibility:** Documents can be accessed through supported browsers and mobile apps.

### 1.3 Where is Google Docs Used?

- Academic assignments and project reports.
- Research papers and documentation.
- Resumes and professional documents.
- Meeting notes and collaborative writing.
- Business reports and proposals.
- Shared documents and team projects.

### 1.4 Getting Started

Google Docs can be accessed through a web browser or its mobile application.

**Steps to get started:**

1. Visit [Google Docs](https://docs.google.com/).
2. Sign in using your Google account.
3. Click **Blank Document** to create a new document.
4. Enter your content.
5. Use the toolbar and menus to format the document.
6. Changes are automatically saved to Google Drive.

### 1.5 Google Docs Interface

Some important elements of the Google Docs interface:

| Element | Purpose |
|---|---|
| Menu Bar | Provides options such as File, Edit, View, Insert, and Format. |
| Toolbar | Contains frequently used formatting tools. |
| Document Area | Main workspace for writing and editing. |
| Ruler | Helps adjust margins and paragraph indentation. |
| Comments | Allows users to add feedback and suggestions. |
| Share Button | Controls document access and collaboration. |

## 2. Document Creation & Management

Google Docs provides tools to create, edit, organize, import, and export documents.

### 2.1 Creating a Document

A new document can be created using:

1. Open [Google Docs](https://docs.google.com/).
2. Click **Blank Document**.
3. Enter the document title.
4. Start writing and editing your content.

You can also create documents using Google Drive by selecting **New → Google Docs**.

### 2.2 Renaming a Document

1. Open the document.
2. Click the document name at the top-left corner.
3. Enter the new name.
4. Press Enter.

### 2.3 Opening and Managing Documents

Google Docs allows users to access documents through Google Drive.

Common actions include:
- Opening existing documents.
- Making copies of documents.
- Moving documents into folders.
- Adding documents to starred items.
- Deleting documents.

### 2.4 Importing Documents

Google Docs supports importing files from your computer.

Common supported formats include:
- Microsoft Word (`.docx`)
- OpenDocument Text (`.odt`)
- Rich Text Format (`.rtf`)
- Plain Text (`.txt`)
- HTML (`.html`)

**Steps:**

1. Open Google Docs.
2. Select **File → Open**.
3. Choose the Upload tab.
4. Select a file from your computer.
5. Open the uploaded document.

Formatting may change when importing files from other formats.

### 2.5 Exporting and Downloading Documents

Google Docs allows documents to be downloaded in different formats.

**Steps:**

1. Open the document.
2. Select **File → Download**.
3. Choose the required format.

Common export formats:

| Format | Purpose |
|---|---|
| `.docx` | Microsoft Word documents. |
| `.pdf` | Sharing and printing documents. |
| `.odt` | OpenDocument Text files. |
| `.rtf` | Rich Text Format. |
| `.txt` | Plain text files. |
| `.html` | Web page format. |

### 2.6 Making a Copy

To create a duplicate of an existing document:

1. Open the document.
2. Select **File → Make a copy**.
3. Enter the new document name.
4. Choose its destination folder.
5. Click **Make a copy**.

The copied document is saved separately from the original.

### 2.7 Version History

Google Docs automatically maintains document versions.

To view previous versions:

1. Open the document.
2. Select **File → Version history → See version history**.
3. Select a previous version.
4. Review the changes.
5. Restore the version if required.

Version history is useful for recovering earlier content and tracking document changes.
## 3. Text Formatting & Paragraphs

Google Docs provides formatting tools to customize text appearance, organize paragraphs, and improve document readability.

### 3.1 Basic Text Formatting

The toolbar provides common text formatting options.

| Feature | Purpose |
|---|---|
| Bold | Makes text bold. |
| Italic | Makes text italic. |
| Underline | Underlines text. |
| Strikethrough | Draws a line through text. |
| Text Color | Changes the text color. |
| Highlight Color | Highlights selected text. |

### 3.2 Font and Font Size

Users can change the font family and size using the toolbar.

**Steps:**
1. Select the required text.
2. Open the font dropdown.
3. Choose a font.
4. Select or enter the desired font size.

Common font families include Arial, Calibri, Times New Roman, and Roboto, depending on availability.

### 3.3 Text Alignment

Google Docs provides four main alignment options.

| Alignment | Description |
|---|---|
| Left | Aligns text to the left margin. |
| Center | Centers text between margins. |
| Right | Aligns text to the right margin. |
| Justify | Aligns text evenly along both margins. |

**Steps:**
1. Select the paragraph.
2. Open the alignment option in the toolbar.
3. Choose the required alignment.

### 3.4 Line and Paragraph Spacing

Line spacing controls the vertical distance between lines of text.

**Steps:**
1. Select the required paragraph.
2. Click **Format → Line & paragraph spacing**.
3. Choose the desired spacing.

Common options include:
- Single
- 1.15
- 1.5
- Double

Additional options allow users to add or remove space before and after paragraphs.

### 3.5 Bulleted and Numbered Lists

Google Docs supports different list formats.

**Bulleted Lists:**
- Used for unordered information.
- Created using the bulleted list toolbar option.

**Numbered Lists:**
1. Used for ordered information.
2. Created using the numbered list toolbar option.

Nested lists can be created using the Increase Indent and Decrease Indent options.

### 3.6 Headings and Styles

Google Docs provides predefined text styles to organize documents.

| Style | Purpose |
|---|---|
| Normal text | Regular paragraph content. |
| Title | Main document title. |
| Subtitle | Additional title information. |
| Heading 1 | Main section heading. |
| Heading 2 | Subsection heading. |
| Heading 3 | Lower-level heading. |

**Steps:**
1. Select the text.
2. Open the Styles dropdown in the toolbar.
3. Choose the required style.

Using heading styles makes it easier to generate a table of contents and navigate long documents.

### 3.7 Indentation

Indentation controls the distance of a paragraph from the page margins.

Google Docs provides:
- Increase indent.
- Decrease indent.
- First-line indent.
- Hanging indent.

The ruler can also be used to adjust paragraph indentation.

## 4. Page Layout & Formatting

Google Docs provides page setup and formatting tools to control document appearance, spacing, and page organization.

### 4.1 Page Setup

Page setup controls the overall layout of a document.

**Steps:**
1. Open the document.
2. Select **File → Page setup**.
3. Choose the required settings.
4. Click **OK** or set them as default.

Common page setup options:

| Option | Description |
|---|---|
| Paper Size | Selects the document paper size. |
| Orientation | Changes between portrait and landscape. |
| Margins | Controls the space around the page. |
| Page Color | Changes the page background color. |
| Apply To | Applies settings to the whole document or selected sections where supported. |

### 4.2 Page Orientation

Google Docs supports two main page orientations:

- **Portrait:** Vertical page layout, commonly used for reports and assignments.
- **Landscape:** Horizontal page layout, useful for wide tables and diagrams.

**Steps:**

1. Select **File → Page setup**.
2. Choose Portrait or Landscape.
3. Click OK.

### 4.3 Page Margins

Margins define the blank space between the document content and page edges.

Margins can be adjusted using:
- File → Page setup.
- The ruler, where applicable.

Common margin settings include top, bottom, left, and right margins.

### 4.4 Page Breaks and Section Breaks

Page breaks and section breaks help organize document content.

**Page Break:**

Starts content on a new page.

Shortcut:
- Windows: `Ctrl + Enter`
- Mac: `⌘ + Enter`

**Section Breaks:**

Section breaks divide a document into sections with independent formatting settings.

Available options include:
- Section break (next page).
- Section break (continuous).

They are useful when different parts of a document require different page layouts, headers, footers, or numbering.

### 4.5 Headers and Footers

Headers appear at the top of pages, while footers appear at the bottom.

**Steps:**

1. Select **Insert → Page elements → Headers & footers** (menu wording may vary).
2. Choose Header or Footer.
3. Enter the required content.
4. Adjust formatting as needed.

Common uses:
- Document titles.
- Author names.
- Page numbers.
- Institution details.

### 4.6 Page Numbers

Google Docs allows automatic page numbering.

**Steps:**

1. Select **Insert → Page elements → Page numbers**.
2. Choose the desired numbering position.
3. Apply the numbering style.

Depending on the selected option, page numbers can appear in headers or footers.

### 4.7 Watermarks

Watermarks display text or images behind document content.

**Steps:**

1. Select **Insert → Page elements → Watermark**.
2. Choose Text or Image.
3. Customize the appearance.
4. Apply the watermark.

Watermarks are commonly used for labels such as DRAFT, CONFIDENTIAL, and SAMPLE.

## 5. Tables, Images & Drawings

Google Docs provides tools to insert and customize tables, images, and drawings to make documents more informative and visually organized.

### 5.1 Inserting Tables

Tables are used to organize information into rows and columns.

**Steps:**

1. Select **Insert → Table**.
2. Choose the required number of rows and columns.
3. Enter the content into the cells.

**Table Operations:**

- Add or delete rows and columns.
- Merge or split cells.
- Resize columns and rows.
- Change cell background colors.
- Adjust borders and alignment.

### 5.2 Formatting Tables

Tables can be customized using table properties.

**Steps:**

1. Right-click inside a table.
2. Select **Table properties**.
3. Adjust the required settings.

Common formatting options:

| Option | Purpose |
|---|---|
| Table alignment | Positions the table. |
| Column width | Adjusts column size. |
| Row height | Controls row height. |
| Cell padding | Adjusts space inside cells. |
| Border color | Changes border appearance. |
| Cell background | Changes cell background color. |
| Table border | Controls border width and style. |

### 5.3 Inserting Images

Google Docs supports inserting images from different sources.

**Steps:**

1. Select **Insert → Image**.
2. Choose the image source.
3. Select or upload an image.
4. Insert it into the document.

Available sources may include:
- Upload from computer.
- Search the web.
- Google Drive.
- Google Photos.
- Camera (where supported).

### 5.4 Image Positioning and Wrapping

Google Docs provides different options for positioning images relative to text.

| Option | Description |
|---|---|
| In line | Treats the image like a text character. |
| Wrap text | Allows text to flow around the image. |
| Break text | Places the image between blocks of text. |
| Behind text | Places the image behind document text. |
| In front of text | Places the image over document text. |

Images can also be resized, cropped, and rotated.

### 5.5 Inserting Drawings

Google Docs allows users to create diagrams and illustrations using its drawing tool.

**Steps:**

1. Select **Insert → Drawing → New**.
2. Use shapes, lines, arrows, and text boxes.
3. Customize the drawing.
4. Click **Save and close**.

Drawings can be used for:
- Flowcharts.
- Basic diagrams.
- Process illustrations.
- Organizational charts.

### 5.6 Charts

Charts can be inserted using Google Docs' chart tools or linked from Google Sheets.

**Steps:**

1. Select **Insert → Chart**.
2. Choose a chart type.
3. Edit the chart data in Google Sheets if required.
4. Update the chart in Google Docs after modifying the source data.

Common chart types include:
- Bar charts.
- Column charts.
- Line charts.
- Pie charts.

## 6. References & Document Tools

Google Docs provides tools to manage document references, navigate long documents, and add supporting information.

### 6.1 Table of Contents

A table of contents automatically lists document headings and helps readers navigate long documents.

**Steps:**

1. Apply heading styles such as Heading 1, Heading 2, and Heading 3.
2. Place the cursor where the table of contents should appear.
3. Select **Insert → Page elements → Table of contents** (menu wording may vary).
4. Choose a display style.

The table of contents can be refreshed when document headings or page positions change.

### 6.2 Footnotes

Footnotes provide additional information or explanations at the bottom of a page.

**Steps:**

1. Place the cursor where the footnote reference is needed.
2. Select **Insert → Footnote**.
3. Enter the additional information in the footnote area.

Shortcut:
- Windows: `Ctrl + Alt + F`
- Mac: `⌘ + Option + F`

### 6.3 Citations

Google Docs includes a citation tool for adding references to academic and research documents.

**Steps:**

1. Select **Tools → Citations**.
2. Choose a citation style.
3. Add a source manually or using the available search options.
4. Insert an in-text citation.
5. Insert the bibliography when required.

Common citation styles include:
- APA
- MLA
- Chicago Author-Date

### 6.4 Bookmarks

Bookmarks allow users to create links to specific locations within a document.

**Steps:**

1. Place the cursor at the required location.
2. Select **Insert → Bookmark**.
3. A bookmark marker appears.
4. Copy its link or use it when creating a hyperlink.

Bookmarks are useful for navigating lengthy documents.

### 6.5 Hyperlinks

Hyperlinks connect text or objects to websites, email addresses, or locations within a document.

**Steps:**

1. Select the text.
2. Press `Ctrl + K` (Windows) or `⌘ + K` (Mac).
3. Enter the URL or select a document location.
4. Click Apply.

### 6.6 Word Count

Google Docs provides a word-count tool to check document length.

**Steps:**

1. Select **Tools → Word count**.
2. View the number of pages, words, characters, and characters excluding spaces.

Shortcut:
- Windows: `Ctrl + Shift + C`
- Mac: `⌘ + Shift + C`

The word count tool can also be set to display a live count while typing.

### 6.7 Find and Replace

Find and Replace helps locate specific words or phrases and replace them throughout a document.

**Steps:**

1. Select **Edit → Find and replace**.
2. Enter the word or phrase to find.
3. Enter the replacement text.
4. Choose Find, Replace, or Replace all.

Shortcut:
- Windows: `Ctrl + H`
- Mac: `⌘ + Shift + H`

## 7. Collaboration & Sharing

Google Docs supports real-time collaboration, allowing multiple users to work on the same document.

### 7.1 Sharing a Document

Documents can be shared with specific people or through a shareable link.

**Steps:**

1. Open the document.
2. Click the **Share** button.
3. Enter the email addresses of the people you want to share with.
4. Choose their access permissions.
5. Click Send.

### 7.2 Access Permissions

Google Docs provides three main sharing roles.

| Role | Permissions |
|---|---|
| Viewer | Can view the document but cannot edit it. |
| Commenter | Can view and add comments or suggestions. |
| Editor | Can edit the document and make changes. |

Access can also be restricted or provided through a link, depending on sharing settings.

### 7.3 Real-Time Collaboration

Multiple users can edit the same document simultaneously.

Features include:
- Live updates to document content.
- Visibility of collaborators' cursors.
- Automatic saving of changes.
- Shared access to comments and suggestions.

### 7.4 Comments

Comments allow collaborators to provide feedback without directly changing the document text.

**Steps:**

1. Select the required text.
2. Select **Insert → Comment** or use the comment shortcut.
3. Enter the comment.
4. Click Comment.

Comments can be replied to, resolved, and reopened.

### 7.5 Suggesting Mode

Suggesting mode allows users to propose changes without directly modifying the original text.

**Steps:**

1. Open the editing mode dropdown near the top-right corner.
2. Select **Suggesting**.
3. Make the required changes.
4. The document owner or an editor can accept or reject the suggestions.

### 7.6 Version History

Version history allows users to track previous document versions and restore earlier content.

**Steps:**

1. Select **File → Version history → See version history**.
2. Choose a previous version.
3. Review the changes.
4. Restore the version if required.

Users can also name important versions to make them easier to identify.

### 7.7 Offline Access

Google Docs can support offline editing when offline access is enabled and configured.

**General steps:**

1. Open Google Drive settings.
2. Enable offline access.
3. Make the required document available offline.
4. Edit the document without an internet connection.

Changes are synchronized when the device reconnects to the internet.

### 8.2 Common Problems and Solutions

| Problem | Possible Solution |
|---|---|
| Changes not appearing | Check internet connectivity and synchronization. |
| Unable to edit a document | Check whether you have Editor access. |
| Formatting changes after importing | Review formatting and adjust document styles. |
| Images not displaying | Check image availability and upload status. |
| Document not opening | Refresh the browser or try another supported browser. |
| Offline changes not syncing | Reconnect to the internet and allow synchronization. |
| Missing content | Check version history for earlier versions. |
